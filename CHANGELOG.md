# История изменений Star Typing Web

## 0.2.0 — 17.10.2026 — Орион, Docker-ярлык, автопроверка обновлений

### Добавлено
- **Гид Орион:** вызов кнопкой / `=` / F8 / палитра; RU ASR; mute радио на весь диалог; шутки и смена волны голосом.
- **Слайдшоу:** ← → волна, ↑ ↓ громкость; после выхода масштаб UI сохраняется.
- **Ярлык Windows:** `install-desktop-shortcut.bat` / `start-star-typing-web.bat` — подъём всех 4 контейнеров с healthchecks.
- **Обновления:** проверка GitHub Releases в Настройках и баннер при новой версии (образ — через ярлык `/rebuild`).

### Исправлено
- Чёрный экран в Chrome после смены вкладок (service worker больше не кэширует JS/CSS).
- Не все контейнеры успевали стать healthy до открытия браузера.

## 0.1.0 — 14.10.2026 — первый веб-релиз

Пульт пилота в браузере: мостик, английский, скорочтение, радио, отдых, настройки; Docker Compose.
