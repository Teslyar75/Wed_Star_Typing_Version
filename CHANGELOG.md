# История изменений Star Typing Web

## Unreleased

### Добавлено
- **Бортовой гид — полный пул шуток/фактов (desktop guide_idle):** 60 шуток + 60 фактов + заходы/system на ru/en/uk/de; JSON по языку и категории (`/guide_content/<lang>/…`, `/api/guide/content`); мешок без повторов; интервалы 5–10 / 10–20 / 20–40 мин; Enter/Esc. Принятые шутки/факты пишутся в чат Ориона через `POST /api/orion/remember` с `kind=joke|fact` (формат desktop `orion.remember`). **Desktop** показывает toast+аудио и в чат не пишет; **ONLINE ambient** (редко, кулдаун, только когда агент свободен, выключатель в Настройки→Гид) — web-дополнение, на desktop нет.
- **Орион — индикатор связи:** зелёный / жёлтый / красный / серый в шапке чата и на вкладке Агенты; опрос `/api/orion/config` и `/api/orion/health` (~20 с, только при видимой вкладке); клик по красному — повторная проверка и подсказка (мост, ключ, таймаут).

### Исправлено
- **Мост OpenCode — runtime path:** `.runtime/opencode_bridge.json` всегда пишется в корень web-репо (каталог с `tools/`), а не в родительский `PROJECT_DIR` десктопа. Баг: проверка `docker-compose.yml` шла в `tools/` → fallback на `D:\My_New_Stamina\.runtime`, тогда как docker-compose монтирует `web_star_typing/.runtime`. Override `ORION_OPENCODE_RUNTIME` сохранён; `start-star-typing-web.bat` читает тот же путь.
- **Безопасность:** изоляция texts (auth + pilot_texts / is_public), лимиты upload (413), SSRF для исходящих HTTP включая BYO Orion (`app/ssrf.py`).
- **Мост OpenCode:** автовыбор порта при WinError 10013/10048 (Hyper-V excluded ranges) и занятом порте; runtime-файл `.runtime/opencode_bridge.json` монтируется в backend — `/api/orion/config` видит `available=true` на нестандартном порту. `ORION_OPENCODE_PORT` остаётся предпочтительным. Второй экземпляр моста не стартует, если живой уже есть.
- **Мост OpenCode:** CLI запускается с `ORION_SILENT_SAY=1`, чтобы не дублировать озвучку (локальный `say.py` / голос веба).

## 0.3.0 — 08.11.2026 — Орион как на десктопе, журнал, дзен, OpenCode

### Добавлено
- **Орион:** три вкладки Чат / Агенты / Архив; дефолтный агент с моделью opencode/deepseek-v4.1-flash-free.
- **Мост OpenCode** на хосте (по умолчанию :8765, tools/opencode_bridge.py) — тот же CLI, что у десктопа, из Docker через host.docker.internal.
- **Голос:** тумблер ГОЛОС/СТОП, Web Speech + TTS; старт распознавания в жесте click.
- **Метки:** правый клик копирует место (zone/subtab/x,y) в буфер и в контекст чата Ориона.
- **Бортжурнал:** вкладки Обзор + Monkeytype; Ctrl+M полностью подменяет UI дзен-порталом.
- **Английский склад:** CEFR, глаголы, наборы, качество пакетов.

### Исправлено
- HTTP 502 на длинном ответе OpenCode: таймауты Caddy 300 с.
- Кнопка «Голос» больше не гаснет сразу после включения.
- **Автообновление с GitHub:** ярлык тянет `origin/master` при старте и пересобирает образы; в Настройках — «Обновить сейчас».

Журнал сессии: docs/web/SESSION_2026-11-08.md.


## 0.2.0 — 17.10.2026 — Орион, Docker-ярлык, автопроверка обновлений

### Добавлено
- **Гид Орион:** вызов кнопкой / `=` / F8 / палитра; RU ASR; mute радио на весь диалог; шутки и смена волны голосом.
- **Слайдшоу:** ← → волна, ↑ ↓ громкость; после выхода масштаб UI сохраняется.
- **Ярлык Windows:** `install-desktop-shortcut.bat` / `start-star-typing-web.bat` — подъём всех 4 контейнеров с healthchecks.
- **Обновления:** проверка GitHub Releases в Настройках и баннер при новой версии (образ — через ярлык `/rebuild`).

### Исправлено
- Чёрный экран в Chrome после смены вкладок (service worker больше не кэширует JS/CSS).
- Не все контейнеры успевали стать healthy до открытия браузера.
