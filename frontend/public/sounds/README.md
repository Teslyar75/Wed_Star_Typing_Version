# Сэмплы кабины

Положите сюда файлы (любой из расширений):

- `click.ogg` / `click.mp3` / `click.wav`
- `error.ogg` / `error.mp3` / `error.wav`
- `finish.ogg` / `finish.mp3` / `finish.wav`

Источник на десктопе: `stamina/sounds/` (если появятся).  
Пока файлов нет — UI использует синтезатор Web Audio (`fx/sounds.ts`).
