# WEB_PORT_PLAN — подтягивание веба до текущего десктопа

Статус: фаза 1 (только чтение + план). Веб-код не менялся.
Шаблон и эталон — десктоп `stamina/` (alt UI, `docs/ALT_UI.md`, `docs/skins/ALT_SKIN_GUIDE.md`, `ALT_UI_AGENT_PROMPT.md`).
Направление только одно: десктоп → веб. На десктоп ничего не переносим.
Возможности, которые есть только в вебе, сохраняем как есть:
- PWA и SW;
- Caddy и Docker;
- ContinueHub;
- Ctrl+K и палитра;
- ASR на сервере;
- updates-баннер;
- lounge-score API;
- guest/dossier.

## Главное правило веба: без прокрутки

Веб нарочно сделан так, чтобы всё помещалось в окно и прокручивать мышью ничего не требовалось. Это правило сохраняем.

Длинные списки с десктопа переносим без скролла:
- аккордеон настроек;
- звёздные карты;
- результаты архива;
- чат Ориона.

Для них используем:
- пагинацию;
- адаптивные сетки по размеру окна;
- вкладки или шаги;
- сворачиваемые панели.

Проверка: на 1366×768 и 1920×1080 у страницы не должно быть прокрутки (`scrollHeight <= innerHeight`, Playwright).

Если функция без скролла не помещается, не добавляем прокрутку: останавливаемся и предлагаем варианты.

## Ограничения веба

- Браузер: нет глобальных хоткеев ОС и нет доступа к `%APPDATA%`. Данные хранятся в API/SQLite и localStorage/IndexedDB. Аудио только после жеста пользователя.
- Логика десктопа переносится импортом из `stamina/` на бэкенде (как vocab и missions). Tk-UI не переносится, а переписывается на React.
- i18n: каждая новая строка сразу во всех 4 локалях (`localeKeys.test.ts`).
- Адаптивность: окна от 360 px до 4K, тач. Сетки на CSS вместо `cols_for`.
- SW-кэш: при изменении оболочки поднимать версию `st-shell-vNN`.
- Docker и Caddy не ломать. `stamina/` не трогать.

## Порядок работ

Один отсек за итерацию, один шаблон, одна ветка `agent/grok/web-port`, коммит на каждый отсек.

0. **Каркас:** переключатель alt/classic, `CompartmentHeader` (крошки и ОБЗОР со скошенными углами через clip-path), правила навигации, правило dropdown, модель skin×variant.
1. **Мостик** — эталон шаблона, с замером производительности.
2. **Английский**, вместе со звёздными картами сеткой.
3. **Скорочтение**, с КНИГА-стопором.
4. **Радио.**
5. **Орион:** чат и панель задач. Нужен API `task_progress`.
6. **Настройки.**
7. **«Без прокрутки» и производительность** — сквозной проход на 1366×768 и 1920×1080.
8. **Обои и варианты** для остальных веб-скинов.
9. **Lounge** — при необходимости.

На каждый отсек: план, код, тесты, скриншоты skin×variant, запись итога в журнал (по образцу ALT_UI.md).

## Подход к тестам

- `npm run build` — tsc без ошибок, плюс `npm run lint` и `npm test` (vitest). Бэкенд: `pytest -q`.
- Playwright (`npm run test:e2e`): на каждый отсек сценарий «открыть, проверить шапку, крошки и ОБЗОР, проверить отсутствие прокрутки на 1366×768 и 1920×1080, вернуться». Скриншоты spaceship и steampunk × варианты.
- Реальный браузер: проверка вручную или через Playwright headed на 1366×768 и 1920×1080, плюс мобильная ширина.
- Производительность: Playwright trace или Lighthouse на мостике и при переключении вкладок.
- Регрессия: существующие e2e (crew-session, english-hub, mission-drill) должны остаться зелёными.

## Журнал

### Шаг 1 — каркас (готово)

- **Вариант интерфейса.** `shell/uiVariant.ts`: `classic` (по умолчанию, без изменений) или `alt`. Хранится в `localStorage` `st_ui_variant`, выставляет `html[data-ui-variant]`. Переключатель «Вариант: Классика / Пульт-кабина» и подпись «Скин + вариант» — в Настройки → Скины (`SkinPicker`).
- **Шапка отсека.** `shell/CompartmentHeader.tsx` и `compartments.ts`: «◈ Заголовок» и кнопка «ОБЗОР ▾» со скошенными углами (clip-path), под ними крошки (`PathCrumbs`).
- **Меню ОБЗОР.** Меню с ✓ у текущего экрана — единственный путь к экранам отсека: подменю мостика в alt скрыто. Меню рендерится через portal поверх сцены.
- **Переводы.** i18n ru/en/uk/de: `alt_overview`, `alt_variant`, `alt_variant_classic`, `alt_variant_alt`, `alt_skin_variant`.
- **Тесты.**
  - vitest: `shell/uiVariant.test.ts`.
  - e2e: `e2e/alt-ui.spec.ts` — alt-шапка spaceship и steampunk, классика без изменений, нет прокрутки на 1366 и 1920.
- **Ещё не сделано.**
  - Вариант пока общий, а не у каждого пилота.
  - Выбора варианта в окне входа нет.
  - Обоев по отсекам нет.

### Шаги 2–6 (Мостик, Английский, Скорочтение, Радио, Настройки)
- Вариант интерфейса хранится на пилота: `st_ui_variant:<позывной>` (без пилота — общий `st_ui_variant`); App привязывает вариант при входе пилота.
- Окно входа: строка «Вариант» (Классика / Пульт-кабина) у выбранного пилота.
- ОБЗОР берёт цвет из скина (`--st-accent` / `--st-bg`).
- Отсеки English/Speed/Radio/Settings публикуют свои экраны (`setZoneScreens`), ОБЗОР ведёт по ним через `goDeep`; в alt их собственные строки вкладок скрыты, классика без изменений.
- Проверка `e2e/alt-compartments.spec.ts`: 29 экранов × 2 скина × 1366×768 и 1920×1080 — прокрутки страницы нет (0 px везде).
- Орион: в вебе отдельного отсека нет — не переносился, нужны решения (см. отчёт).
