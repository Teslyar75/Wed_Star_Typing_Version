# Стоимость хостинга Star Typing Web (Украина)

Оценка **годовых** затрат на онлайн-версию с **нормальной скоростью** (без «засыпания» бесплатных тарифов).  
Архитектура и техника: [HOSTING_GITHUB_PAGES.md](HOSTING_GITHUB_PAGES.md).

Цены ориентировочные на 2026 год (EUR/USD → гривна по курсу ~45 ₴/€, ~41 ₴/$ — пересчитывайте по актуальному курсу). НДС и комиссии карт могут добавить 0–20 %.

---

## 1. Что считать «нормальной скоростью»

| Не подходит | Подходит |
| --- | --- |
| Free Render / Free Fly с sleep (~30 с на первый запрос) | Always-on VPS или платный API без sleep |
| Только GitHub Pages без API | UI + постоянно живой backend |
| Хостинг только в далёком US при аудитории в UA | Датацентр в **EU** (DE / FI / PL) — пинг из Украины обычно 30–60 мс |

GitHub Pages для UI — **бесплатно** и достаточно быстро (CDN). Узкое место — API и БД.

## 2. Сводка: сколько в год

| Вариант | В месяц | **В год** | ≈ гривны / год | Комментарий |
| --- | --- | --- | --- | --- |
| Pages (UI) + **платный** API (Render/Fly ~1 GB RAM) | ~$7–15 | **~$80–180** | **~3 500–8 000 ₴** | Схема Pages + API из документа |
| **Один VPS** в EU (Hetzner ~2 vCPU / 4 GB) + Docker весь стек | ~€5–8 + НДС | **~€60–110** | **~3 000–5 500 ₴** | Самый выгодный «нормальный» вариант |
| VPS побольше (4–8 GB) «с запасом» | ~€8–20 | **~€100–250** | **~4 500–11 000 ₴** | Много пилотов / TTS / БД |
| Managed «как продукт» (Render + Postgres + бэкапы) | $25–50+ | **$300–600+** | **~12 000–25 000 ₴+** | Уже не hobby |

### Практичный ответ для Star Typing Web

- **Минимум для стабильной работы:** примерно **3 000–8 000 ₴/год**.  
- **Комфортно «не думать»:** примерно **5 000–12 000 ₴/год** (VPS 4 GB + бэкапы + домен).

## 3. Разбор вариантов

### 3.1. GitHub Pages + платный API (Render / Fly / Railway)

```text
UI  → GitHub Pages          ≈ 0 ₴
API → paid always-on        ≈ $7–15 / мес
БД  → SQLite на диске API или маленький Postgres
```

| Плюсы | Минусы |
| --- | --- |
| UI бесплатно, деплой из Actions | Два места (Pages + API) |
| Близко к схеме в HOSTING_GITHUB_PAGES | Free-tier API **не** брать для «нормальной» скорости |
| Масштабировать API отдельно | Cookie/CORS кросс-домен |

**Итого в год:** порядка **3 500–8 000 ₴** (только API + мелочи).

### 3.2. Один VPS в Европе + Docker (рекомендация по цене/качеству)

Пример: **Hetzner Cloud** класс CX22 / CX23 — около **€4.5–6 / мес** net (2 vCPU, 4 GB RAM, 40 GB NVMe, большой трафик). С НДС для частного лица в EU — ближе к **€5–8 / мес**.

На одном VPS:

- `docker compose` как дома (frontend + backend + postgres + caddy);
- один домен / IP;
- без кросс-доменных cookie.

| Плюсы | Минусы |
| --- | --- |
| Дешевле связки Pages+paid API при том же «always on» | Нужно самому обновлять / бэкапить |
| Пинг из Украины хороший (DE/FI) | Нет «кнопки масштаба» PaaS |
| Полный стек как в репо | Ответственность за безопасность (SSH, SECRET_KEY) |

**Итого в год:** порядка **3 000–5 500 ₴** за машину; с бэкапами и доменом — **~4 000–7 000 ₴**.

Провайдеры в том же классе: Contabo, OVH VPS, иногда украинские VPS (проверять пинг и аплинк).

### 3.3. Managed PaaS «как продукт»

Render/Fly/Railway: всегда включённый web + managed Postgres + автобэкапы + больше RAM.

**Итого в год:** часто **$300–600+** (~12 000–25 000 ₴) — имеет смысл при платной подписке / серьёзной нагрузке, не для личного демо.

## 6. Пример сметы «комфорт из Украины»

| Позиция | Оценка / год |
| --- | --- |
| Hetzner CX23 (или аналог), EU, с НДС | ~4 500 ₴ |
| Бэкапы | ~900 ₴ |
| Домен | ~500 ₴ |
| **Итого** | **~5 900 ₴ / год** |

Альтернатива той же суммы: Pages (0) + платный always-on API (~5 000–7 000 ₴) — удобнее деплой фронта из Actions, чуть сложнее cookie/CORS.

## 9. Краткий вывод

Для Star Typing Web с нормальной скоростью из Украины закладывайте:

**около 3 000–8 000 ₴ в год** на hobby/always-on,  
**около 5 000–12 000 ₴ в год** с запасом (бэкапы + домен + чуть больше RAM).

Самый выгодный путь по цене и простоте эксплуатации: **один европейский VPS + Docker**, как в `docker-compose.yml`.  
Схема **GitHub Pages + отдельный API** — чуть гибче для фронта, по деньгам сопоставима, если API не на free sleep.
