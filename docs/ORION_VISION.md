# ОРИОН — бортовой разум: идея, сделано, будущее

Документ фиксирует продуктовую линию гида Ориона в веб-сервисе Star Typing (`web_star_typing`).  
Цель — чтобы на звездолёт **хотелось возвращаться** не только ради слепой печати и музыки, а ради живого компаньона на мостике.

Родственный десктоп ([My_Stamina](https://github.com/Teslyar75/My_Stamina)): гид пока **в планах** → [docs/ORION_VISION.md](https://github.com/Teslyar75/My_Stamina/blob/feat/ship-slideshow/docs/ORION_VISION.md).

---

## Цель, которую мы преследуем

Создать онлайн-сервис, где пилот тренирует печать, слушает радио, читает — и при этом чувствует, что **на корабле кто-то живёт**: бортовой разум Орион.

Орион — не «подсказка по таймеру» и не безликий чат-бот в углу экрана. Это персонаж:

- вежливый дворецкий с сухой иронией;
- иногда **скучает** и сам вмешивается в тишину или в радио, чтобы поговорить с *этим* пилотом;
- по вызову **слушает** пилота и **выполняет** простые поручения;
- запоминает контекст именно этого пилота (позже — по-настоящему, через ИИ);
- помогает с английским и другими занятиями на борту.

В перспективе: **подписка на ИИ-агента** (ChatGPT или аналог), который реально живёт в звездолёте, общается с разными пилотами, помнит темы разговоров с каждым и развивается вместе с ними.

## Что уже сделано (каркас «здесь кто-то живёт»)

### Персона и оболочка

| Что | Где / как |
| --- | --- |
| Имя, титул «бортовой разум», персона | `packages/guides/ship_ai.json` |
| Реплики (знакомство, зоны, события, шутки) | `packages/guides/lines/ship_ai.ru.json` |
| Выбор гида / «Без гида» на входе | стартовое окно + `guides.ts` |
| Настройки: гид, частота, голос, шутки | Настройки → «Гид» |
| Состояние на пилота | `localStorage` → `st_guide::<позывной>` |
| Голос | edge-tts / Web Speech, `ru-RU-DmitryNeural` |

### События (не только тишина)

- Первое знакомство, вход в зоны.
- Новое звание, личный рекорд, возвращение после перерыва, серия ошибок.
- Окна ждут паузы в наборе (не мешают печати).
- **Enter** — дальше / согласие; **Esc** — закрыть / «не сейчас»; **Shift+Esc** — больше не показывать этот триггер; **V** — голос вкл/выкл.

### Шутки и «скука»

- Переключатель **«Шутки Ориона»** в настройках гида.
- Орион **сам предлагает** анекдот ~раз в **10 минут** (свой кулдаун, вне общего лимита частоты подсказок).
- Разные реплики для **тишины** и для **играющего радио** («приглушу эфир…»).
- **Enter** — рассказать анекдот; **Esc** — отказаться (шутку не произносит).
- Пока говорит гид — **радио приглушается** (`holdDuck("guide")`).
- Кнопка «Предложить шутку» в настройках — для быстрой проверки тона.

### Голосовой вызов (кнопка ОРИОН)

Кнопка **ОРИОН** в хроме рядом с **СЛАЙДЫ** и **ЭКРАН** (с любой вкладки, в т.ч. в полноэкранном режиме). Гид должен быть выбран (не «Без гида»).

Цепочка:

1. Пилот нажимает **ОРИОН** → радио **сразу замолкает** (полная тишина), чтобы микрофон слышал пилота, а не эфир.
2. Орион говорит: *«Да, я тут, сэр. Что-то нужно?»*
3. Включается **микрофон** (Web Speech, `ru-RU`; нужен Chrome/Edge и разрешение).
4. Пилот говорит команду → Орион **реагирует и выполняет**.
5. Сеанс закончен / отмена → громкость радио возвращается.
6. Повторное нажатие кнопки во время сеанса — отмена.

| Команда пилота (примеры) | Действие Ориона |
| --- | --- |
| «дай шутку», «расскажи анекдот», «joke» | Сразу рассказывает анекдот (окно + голос) |
| «смени волну», «переключи станцию», «next station» | Следующая станция из **избранного** радио + «Переключаю: …» |
| «предыдущую волну» | Предыдущая из избранного |
| неразборчиво / другая фраза | Подсказка: скажите «дай шутку» или «смени волну» |

Файлы: `OrionCallButton.tsx`, `orionCall.ts`, `orionCommands.ts`, `listenPhrase` в `english/asr.ts`, `tellJokeNow` в `guideStore.ts`.

### Слайдшоу

- Кнопка **СЛАЙДЫ** рядом с **ЭКРАН** — запуск с любой вкладки.
- Выход: любая клавиша (стрелки — радио).

## Примеры взаимодействия пилота и Ориона

Ниже — типичные сцены, которые уже можно прожить на вебе (или заложены как характер).

### 1. Первый выход на мостик

| | |
| --- | --- |
| **Ситуация** | Новый пилот выбрал Ориона на входе. |
| **Орион** | Знакомится короткими репликами: кто он, Ctrl+1…6, F1, Enter/Esc. |
| **Пилот** | Enter — дальше; Esc — отложить. |
| **Ощущение** | На борту есть дворецкий, а не пустой экран. |

### 2. Орион сам скучает (тишина)

| | |
| --- | --- |
| **Ситуация** | ~10 минут без окон гида, пилот не печатает. |
| **Орион** | *«Тишина на мостике… мне скучновато. Короткий анекдот, сэр?»* |
| **Пилот** | Enter — слушает шутку; Esc — «не сейчас». |
| **Ощущение** | Компаньон сам инициирует контакт. |

### 3. Орион перебивает радио

| | |
| --- | --- |
| **Ситуация** | Играет радио, сработал кулдаун шуток. |
| **Орион** | *«Прошу прощения за эфир — приглушу радио… Есть анекдот?»* Эфир тише. |
| **Пилот** | Enter / Esc. После речи громкость радио возвращается. |
| **Ощущение** | Орион живёт в том же эфире, что и музыка. |

### 4. Вызов по кнопке — шутка

| | |
| --- | --- |
| **Пилот** | Жмёт **ОРИОН** — радио замолкает. |
| **Орион** | *«Да, я тут, сэр. Что-то нужно?»* → слушает. |
| **Пилот** | *«Дай шутку.»* |
| **Орион** | Рассказывает анекдот; после сеанса эфир снова слышен. |

### 5. Вызов по кнопке — смена волны

| | |
| --- | --- |
| **Пилот** | Жмёт **ОРИОН**, после приветствия: *«Смени волну.»* |
| **Орион** | Переключает избранную станцию: *«Переключаю: …»* |
| **Условие** | В радиорубке есть ★ избранные волны; иначе подскажет добавить. |

### 6. Рекорд и звание

| | |
| --- | --- |
| **Ситуация** | Личный рекорд скорости/точности или новое звание. |
| **Орион** | Короткая реплика с цифрами / новым рангом (когда пилот сделал паузу в наборе). |
| **Ощущение** | Успех замечает не таблица, а напарник. |

### 7. Серия ошибок

| | |
| --- | --- |
| **Ситуация** | Несколько ошибок подряд на одной клавише. |
| **Орион** | Мягко намекает не торопиться, сначала точность. |
| **Пилот** | Enter — понял; Shift+Esc — больше не показывать этот тип подсказки. |

### 8. Возвращение после перерыва

| | |
| --- | --- |
| **Ситуация** | Пилот не заходил несколько дней. |
| **Орион** | Приветствует с учётом паузы («N дней»). |
| **Ощущение** | Корабль помнит, что вас не было. |

## Архитектурный задел под «настоящего» агента

| Сейчас | Потом (ИИ-агент) |
| --- | --- |
| Триггеры + JSON-реплики | Тот же UI / голос; текст генерирует модель |
| Кнопка ОРИОН + набор команд | Свободный диалог; те же duck и кнопка |
| `st_guide::<пилот>` | Серверная память диалогов и профиля |
| Шутки / вклинивание | Агент сам решает, когда заговорить |
| Зоны (мостик, английский…) | Контекст сессии в промпте агента |

Принцип: **снаружи тот же Орион**, внутри — всё умнее и памятливее.

## Будущее (roadmap)

### Расширение голоса

- Больше команд: пауза/продолжить набор, открыть зону, громкость, «что умеешь».
- Свободный диалог при **подписке** на ИИ (сейчас — скриптовые команды).
- Текст + голос в одном канале на мостике.

### Память по пилоту

- История тем разговоров по позывному; прогресс печати и английского.

### Подписка на ИИ-сервис

- Провайдер на сервере, биллинг; без подписки — лёгкий Орион (как сейчас).

### Английский и саморазвитие

- Тренировка языка в разговоре; адаптация тона и частоты вмешательств.

### Зачем возвращаются

Печать и радио — якоря; **разговор с Орионом** — повод зайти «на пять минут» на мостик.
