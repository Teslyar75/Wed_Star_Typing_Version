# ОРИОН — бортовой разум: идея, сделано, будущее

Документ фиксирует продуктовую линию гида Ориона в веб-сервисе Star Typing (`web_star_typing`).  
Цель — чтобы на звездолёт **хотелось возвращаться** не только ради слепой печати и музыки, а ради живого компаньона на мостике.

---

## Цель, которую мы преследуем

Создать онлайн-сервис, где пилот тренирует печать, слушает радио, читает — и при этом чувствует, что **на корабле кто-то живёт**: бортовой разум Орион.

Орион — не «подсказка по таймеру» и не безликий чат-бот в углу экрана. Это персонаж:

- вежливый дворецкий с сухой иронией;
- иногда **скучает** и сам вмешивается в тишину или в радио, чтобы поговорить с *этим* пилотом;
- запоминает контекст именно этого пилота (позже — по-настоящему, через ИИ);
- помогает с английским и другими занятиями на борту.

В перспективе: **подписка на ИИ-агента** (ChatGPT или аналог), который реально живёт в звездолёте, общается с разными пилотами, помнит темы разговоров с каждым и развивается вместе с ними.

## Что уже сделано (каркас «здесь кто-то живёт»)

### Персона и оболочка

| Что | Где / как |
| --- | --- |
| Имя, титул «бортовой разум», персона | `packages/guides/ship_ai.json` |
| Реплики (знакомство, зоны, события, шутки) | `packages/guides/lines/ship_ai.ru.json` |
| Выбор гида / «Без гида» на входе | стартовое окно + `guides.ts` |
| Настройки: гид, частота, голос, шутки | Настройки → «Гид» |
| Состояние на пилота | `localStorage` → `st_guide::<позывной>` |
| Голос | edge-tts / Web Speech, `ru-RU-DmitryNeural` |

### События (не только тишина)

- Первое знакомство, вход в зоны.
- Новое звание, личный рекорд, возвращение после перерыва, серия ошибок.
- Окна ждут паузы в наборе (не мешают печати).
- **Enter** — дальше / согласие; **Esc** — закрыть / «не сейчас»; **Shift+Esc** — больше не показывать этот триггер; **V** — голос вкл/выкл.

### Шутки и «скука» (ощущение живого напарника)

- Переключатель **«Шутки Ориона»** в настройках гида.
- Орион **сам предлагает** анекдот ~раз в **10 минут** (свой кулдаун, вне общего лимита частоты подсказок).
- Разные реплики для **тишины** и для **играющего радио** («приглушу эфир…»).
- **Enter** — рассказать анекдот; **Esc** — отказаться (шутку не произносит).
- Пока говорит гид — **радио приглушается** (`holdDuck("guide")`), после речи громкость возвращается; набор текста не срывает приглушение гида.
- Кнопка «Предложить шутку» в настройках — для быстрой проверки тона.

### Связанный UX мостика (контекст «корабль»)

- Слайдшоу простоя + радио по скину; кнопка **СЛАЙДЫ** рядом с **ЭКРАН** — запуск с любой вкладки.
- Выход из слайдшоу: любая клавиша (стрелки — радио), как и задумано.

Это всё — **скриптовый** Орион. Он уже тренирует ощущение компаньона; память и свободный диалог — следующий слой.

## Архитектурный задел под «настоящего» агента

То, что уже есть, мапится на будущую подписку почти один в один:

| Сейчас | Потом (ИИ-агент) |
| --- | --- |
| Триггеры + JSON-реплики | Тот же UI окна гида / голос; текст генерирует модель |
| `st_guide::<пилот>` | Серверная память диалогов и профиля пилота |
| Шутки / вклинивание в тишину и радио | Агент сам решает, когда заговорить; duck радио остаётся |
| Зоны (мостик, английский, библиотека…) | Контекст сессии: «сейчас на мостике / учит слова / читает» |
| Переключатель шуток / голоса | Политики агента + биллинг подписки |

Принцип: **снаружи тот же Орион**, внутри — всё умнее и памятливее.

## Будущее (roadmap идеи)

Порядок ориентировочный; детали реализации — когда решите подключать сервис / обновить лимиты агента.

### 1. Голосовой вызов Ориона (микрофон)

Пилот должен **взаимодействовать с Орионом голосом**, а не только читать всплывающие реплики.

- **Кнопка микрофона** доступна **из любого места интерфейса** (хром рядом с ЭКРАН / СЛАЙДЫ или плавающая кнопка) — один клик = вызвать Ориона.
- По нажатию включается микрофон: программа **слушает** пилота (ASR; на вебе уже есть задел Vosk / серверный ASR в зоне English).
- Распознанная речь уходит Ориону; он **действует** в характере бортового разума: отвечает голосом (TTS), при необходимости открывает зону, подсказывает, шутит, помогает с английским и т. д.
- Пока Орион слушает / говорит — радио приглушается (тот же duck, что для шуток).
- Повторное нажатие / Esc — остановить прослушивание.
- Без подписки на ИИ: ограниченный набор голосовых команд (скрипт); с подпиской — свободный диалог через агента.

### 2. Диалог на мостике (текст + голос)

- Канал общения с Орионом (не только односторонние всплывающие реплики).
- Пилот отвечает голосом (кнопка микрофона) или текстом; Орион продолжает в характере дворецкого.

### 3. Память по пилоту

- История тем разговоров именно с этим позывным.
- Можно «продолжить с того места», зайти через неделю — Орион помнит.
- Отдельно: прогресс печати, английского, привычки (что любит слушать, когда скучает).

### 4. Подписка на ИИ-сервис

- Вшить провайдера (ChatGPT API / аналог) за подпиской.
- Лимиты, ключи, биллинг — на сервере; клиент не хранит секреты.
- Без подписки остаётся текущий «лёгкий» Орион (скрипты + шутки); с подпиской — живой агент по голосу и тексту.

### 5. Английский и «прочее»

- Тренировка английского в диалоге (исправления, подсказки, миссии через разговор).
- Связка с зоной English / книгами / миссиями.
- Позже: другие гиды (Хоббс, Вера Павловна, Кадет Тим) или тот же агент в разных «масках» скина.

### 6. Саморазвитие системы

- Орион адаптируется к пилоту: тон, частота вмешательств, темы.
- Ощущение саморазвивающегося бортового разума, а не статичного FAQ.

### 7. Зачем люди возвращаются

Не только:

- слепая печать;
- радио и слайдшоу;

но и:

- продолжить разговор с Орионом;
- потренировать язык с тем, кто тебя помнит;
- «зайти на мостик на пять минут» — как к живому месту, а не к тренажёру.

## Коротко одной фразой

**Сейчас:** Орион уже ведёт себя как скучающий бортовой разум и готовит привычку «на корабле есть кто-то свой».  
**Цель:** онлайн-звездолёт, куда возвращаются к печати *и* к живому компаньону.  
**Потом:** кнопка микрофона в любом месте UI → Орион слушает и действует; подписка на ИИ-агента с памятью по пилоту, голосом, английским и развитием вместе с экипажем.
