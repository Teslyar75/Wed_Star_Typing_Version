## Docker

WSL-данные на **D:**; логи Docker на **C:**. Падение: *Disk full* → демон «unable to start». После освобождения C и `docker compose up -d --build` код попал в volume. Затем повторный build после фикса CSS.

```powershell
docker compose up -d --build
# http://localhost  — Ctrl+F5 после деплоя CSS
```
