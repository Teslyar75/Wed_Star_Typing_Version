# Блокеры и неизвестные

Пустое место ≠ «всё хорошо»: если этап не начат, это не блокер.

## Активные

| ID | Суть | Влияние | Обход запрещён |
| --- | --- | --- | --- |
| B1 | Origin `stack_on` недоступен (GitHub source of truth) | PR стек только через `base_branch` + ссылки в теле | Не создавать PR через `gh` / Origin CLI |
| B2 | Merge/deploy/release запрещены, пока Сергей не укажет конкретный scope и latest checks green | PR остаются OPEN | Не merge «потому что зелёный» |
| B3 | `graphify-out` не найден | Не строить граф плана заново | Не искать по почте/Drive/личным сервисам |
| B4 | Обои `docs.jpg` нет в `public/alt_wallpapers` | S2: фолбэк скина, не добавлять чужой jpg | Не выдумывать ассет |
| B5 | Обои `comm.jpg` в web нет | S3: фолбэк скина, как у Документов | Не выдумывать ассет |

## Если этап упирается

1. Зафиксировать ошибку здесь и в PROGRESS (SHA, лог, чего не хватает).
2. Commit + push checkpoint.
3. Остановиться. Не менять модель, не включать paid overage, не обещать бесконечную работу.
4. Документация позволяет возобновление человеком в этом же чате Cursor; сама по себе планировщик не запускает.
