## Общие критерии любого этапа

- Отдельная ветка `cursor/<имя>-2598` от проверенной базы. Не rebase/amend/force-push опубликованного.
- PR через `ManagePullRequest`: `base_branch` = ветка зависимости; в теле — ссылки на предыдущие PR. GitHub SoT: `stack_on` на Origin недоступен.
- Сохранить: PWA, радио-хост, скины, ContinueHub, Орион (как зону), React 19 / Vite / FastAPI.
- 4 локали (ru/uk/en/de), classic/alt, 1366×768 и 1920×1080: **страница** без прокрутки (`scrollHeight - innerHeight ≤ 1`). Внутренняя пагинация — по существующим правилам.
- Данные новых отсеков: существующий web data/API, изоляция по cookie-пилоту, тесты «чужой не читает».
- Точечные тесты при отладке; на финальном HEAD — полный frontend + backend + e2e CI и Docker. Не skip/xfail.
- Не merge / deploy / release. Не письма, не Drive, не внешние трекеры.
- Не начинать следующие отсеки раньше своей очереди. Comm / Lab / Qoder / widget — вне очереди.

## S2 — Документы MVP (текущий)

**Цель:** зона Документы **перед Орионом** (8 зон: bridge, english, speed, lounge, radio, **docs**, orion, settings). Ctrl+6 docs, Ctrl+7 orion, Ctrl+8 settings. Comm по-прежнему нет.

MVP: список, создание/открытие/редактирование; безопасное автосохранение с честным статусом ошибок; снимки/версии как в desktop `stamina/docs.py` (раз в 10 мин, последние 20); печать средствами браузера + print CSS. **Не** вызывать реальную печать в тестах.

Данные в SQL `pilot_docs` / API `/api/docs`, изоляция cookie `get_current_pilot`. Клиентский `pilot_id` игнорировать. Сохранение не теряется при смене документа/вкладки/пилота; поздний ответ не перезаписывает другую запись; 409/ошибка — честно.

Эталон смысла: desktop 3.8.3 docs (список, editor, autosave, versions, print). **Не в S2:** картинки, диктовка, шаблоны, корзина, DOCX/PDF export, почта.

Регрессия: CRUD/изоляция, autosave lifecycle/errors, print markup, навигация и размеры.

Обои `docs.jpg` нет — фолбэк скина, не выдумывать файл.
