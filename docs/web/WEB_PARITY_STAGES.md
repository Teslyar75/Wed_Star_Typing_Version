## Общие критерии любого этапа

- Отдельная ветка `cursor/<имя>-2598` от проверенной базы. Не rebase/amend/force-push опубликованного.
- PR через `ManagePullRequest`: `base_branch` = ветка зависимости; в теле — ссылки на предыдущие PR. GitHub SoT: `stack_on` на Origin недоступен.
- Сохранить: PWA, радио-хост, скины, ContinueHub, Орион (как зону), React 19 / Vite / FastAPI.
- 4 локали (ru/uk/en/de), classic/alt, 1366×768 и 1920×1080: **страница** без прокрутки (`scrollHeight - innerHeight ≤ 1`). Внутренняя пагинация — по существующим правилам.
- Данные новых отсеков: существующий web data/API, изоляция по cookie-пилоту, тесты «чужой не читает» там, где данные личные. Эфир — **общий канал**: чужие сообщения как раз должны быть видны.
- Точечные тесты при отладке; на финальном HEAD — полный frontend + backend + e2e CI и Docker. Не skip/xfail.
- Не merge / deploy / release. Не письма, не Drive, не внешние трекеры.
- Не начинать следующие отсеки раньше своей очереди. Lab / Qoder / widget — вне очереди.

### Desktop 3.8.3 `9622f3e` (read-only) — что такое Эфир

Имя «эфир» встречается в двух местах; это **не одно и то же**:

| Что | Код / док | Смысл |
| --- | --- | --- |
| Зона **ЭФИР** | `stamina/nav.py` `ZONE_ORDER`: `comm` между `radio` и `docs`; `stamina/comm.py`, `comm_screen.py`, `comm_hook.py`; [COMM_ETHER.md](https://github.com/Teslyar75/My_Stamina/blob/9622f3e5dd2f9935a5a3dfb36b68ddbe9b3f7d1a/docs/COMM_ETHER.md); CAPABILITIES §10 | Общий канал экипажа: пилоты пишут **друг другу** |
| Подстраница радиорубки «эфир» | `radio/air`, web `radio_air` | Эфир как **вещание** станции, не чат |

Прежняя трактовка S3 как «только radio» была ошибкой созвучия. Радиорубка уже есть; её изоляция по пилоту на этой ветке **сохранена**, но это не смысл этапа.

Орион (`stamina/orion.py` / `orion_screen.py`, CAPABILITIES §11) — чат с **агентом**, задачи, архив, права. С Эфиром общая только идея «лента + ввод».

| Берём | Источник | Зачем для чата |
