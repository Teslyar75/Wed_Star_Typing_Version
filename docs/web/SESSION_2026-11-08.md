# Сессия 2026-11-08 — журнал, дзен-портал, английский склад, Орион как на десктопе

Краткий журнал. Код: [Wed_Star_Typing_Version](https://github.com/Teslyar75/Wed_Star_Typing_Version) · ветка `agent/grok/web-port` → `master`.

## Цель сессии

1. Свести бортжурнал веба к двум вкладкам (Обзор + Monkeytype), без прокрутки колесом; портал Ctrl+M полностью подменяет UI.
2. Подтянуть английский склад к десктопу: CEFR, глаголы, наборы, качество.
3. Перенести отсек Ориона один в один с десктопного пульта: три вкладки Чат / Агенты / Архив.
4. Подключить ту же модель OpenCode, что на десктопе (`opencode/deepseek-v4.1-flash-free`), и дать голосовой разговор.
5. Порт правой кнопки «геолокации» (метки) с десктопа.

### OpenCode на хосте (мост :8765)

Linux-контейнер не запускает Windows `opencode.exe`. Мост на хосте — тот же CLI, что у десктопа.

| Область | Файлы | Суть |
| --- | --- | --- |
| Мост | `tools/opencode_bridge.py` | stdlib HTTP `0.0.0.0:8765`. GET `/health`, POST `/run`. Ищет `opencode.exe` под `%APPDATA%/npm/node_modules/opencode-ai/bin/`. |
| Запуск | `start-star-typing-web.bat` | Поднимает `py -3 tools\opencode_bridge.py`. |
| Docker | `docker-compose.yml` | `extra_hosts: host.docker.internal`, `ORION_OPENCODE_*`. Backend бьёт в `http://host.docker.internal:8765/run`. |
| Профили | `api_orion.py` | commander → `orion-commander`, observer → `orion-recon`, crew → `orion-chat`. |
| Caddy | `Caddyfile` | `read_timeout` / `write_timeout` 300s — длинный ответ OpenCode больше не режется в HTTP 502. |

| Область | Файлы | Суть |
| --- | --- | --- |

| Жест | `startMic` | `SpeechRecognition.start()` синхронно в click — иначе браузер сразу гасит сессию (после async getUserMedia жест уже не считается). |
| Сессия | `armedRef`, `micGen` | `onend` через 120 мс перезапускает, если тумблер ещё включён; `no-speech` / `aborted` не снимают armed. |
| TTS | `speak()` | Ответ Ориона голосом. Авто-отправь после 2.5 с тишины в режиме autoOn. |

## Как поднять у себя

1. `start-star-typing-web.bat` (Docker + мост OpenCode на `:8765`).
2. В браузере Ctrl+F5.
3. Отсек Орион → Чат → ГОЛОС. Модель по умолчанию — та же, что на десктопе.
4. Правый клик по пульту копирует метку места в буфер и в контекст чата.
5. Ctrl+M — дзен-портал набора.
