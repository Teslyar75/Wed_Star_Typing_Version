## Шаблон новой сессии

Создать `docs/web/SESSION_YYYY-MM-DD.md`:

```markdown
# Сессия YYYY-MM-DD — краткий заголовок

## Цель сессии
…

## Сделано
| Область | Файлы | Суть |
| --- | --- | --- |
| … | … | … |

## Проверка
…

## Не сделано / хвосты
…
```

Затем добавить строку в таблицу «Хронология» выше и ссылку в [README.md](./README.md).
